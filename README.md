# Chico Digital Transformation Lab — Website

Student‑powered digital transformation for local businesses. Built with **Next.js 14 (App Router)** + **Tailwind CSS**.

## Quick start

```bash
npm install
npm run dev
# open http://localhost:3000
```

## Deploy to Vercel

1. Push this folder to a GitHub repo.
2. Import the repo on https://vercel.com (New Project → Deploy).

## Form handling

A stub serverless endpoint is included at `app/api/contact/route.ts`.
Wire it to an email service (e.g., Resend) or a database as needed.
